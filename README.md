Struktura: `<PL|DE>/<YYYY-MM>/STATIC_<litera>-<temat>_<język>_<format>.png`, `REEL_<litera>-<temat>_<wariant>_<język>_9x16.mp4`.
Adres pliku dla Meta: `https://raw.githubusercontent.com/nitekm/coffeebase-ads-assets/main/<ścieżka>`.
